>
> ```typescript
> //方式1
> let inputMethodController = inputMethod.getController();
> inputMethodController.stopInputSession()
> //方式2
> TextInputController.stopEditing()
> //方式3
> this.getUIContext().getFocusController().clearFocus()
> ```

> 获得键盘弹出收起情况：
>
> [获得系统键盘弹出收起: keyboardHeightChange ,不能获得自定义键盘弹出收起 ](https://developer.huawei.com/consumer/cn/doc/harmonyos-references-V5/js-apis-window-V5#onkeyboardheightchange7)
>
> 获取自定义键盘弹出：组件的onAppear方法 ； 获得自定义键盘收起：组件的onDisAppear方法
>
> 组件的onDisAppear方法调用时机比ui效果慢很多，为了自定义键盘收起时及时响应，使用组件的onVisibleAreaChange方法：
>
> ```typescript
> .onVisibleAreaChange([0.0, 1.0], (_, ratio) => {
>     if (ratio == 0) {
>         //自定义键盘收起
>     } })
> ```
