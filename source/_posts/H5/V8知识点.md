## V8引擎基本用法

[官方例子](https://github.com/v8/v8/blob/main/samples/hello-world.cc)

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "include/libplatform/libplatform.h"
#include "include/v8.h"

int main(int argc, char* argv[]) {
  // Initialize V8.
  std::unique_ptr<v8::Platform> platform = v8::platform::NewDefaultPlatform();
  v8::V8::InitializePlatform(platform.get());
  v8::V8::Initialize();
  // Create a new Isolate and make it the current one.
  v8::Isolate::CreateParams create_params;
  create_params.array_buffer_allocator =
      v8::ArrayBuffer::Allocator::NewDefaultAllocator();
  v8::Isolate* isolate = v8::Isolate::New(create_params);
  {
    v8::Isolate::Scope isolate_scope(isolate);
    // Create a stack-allocated handle scope.
    v8::HandleScope handle_scope(isolate);
    // Create a new context.
    v8::Local<v8::Context> context = v8::Context::New(isolate);
    // Enter the context for compiling and running the hello world script.
    v8::Context::Scope context_scope(context);
    // Create a string containing the JavaScript source code.
    v8::Local<v8::String> source =
        v8::String::NewFromUtf8(isolate, "'Hello' + ', World!'",
                                v8::NewStringType::kNormal)
            .ToLocalChecked();
    // Compile the source code.
    v8::Local<v8::Script> script =
        v8::Script::Compile(context, source).ToLocalChecked();
    // Run the script to get the result.
    v8::Local<v8::Value> result = script->Run(context).ToLocalChecked();
    // Convert the result to an UTF8 string and print it.
    v8::String::Utf8Value utf8(isolate, result);
    printf("%s\n", *utf8);
  }
  // Dispose the isolate and tear down V8.
  isolate->Dispose();
  v8::V8::Dispose();
  v8::V8::ShutdownPlatform();
  delete create_params.array_buffer_allocator;
  return 0;
}
```



## 类解析

### 1.**`v8::Isolate::Scope`**

- **作用**：设置当前线程使用的 **Isolate（隔离实例）**。
  - Isolate 是 V8 的独立实例，拥有自己的堆内存、GC 等资源。
  - 多线程环境下，每个线程需绑定一个 Isolate。
- **生命周期**：对象存在期间，所有 V8 API 调用默认使用该 Isolate。

- **典型用法**：

  ```c
  v8::Isolate* isolate = v8::Isolate::New(/* 参数 */);
  {
    v8::Isolate::Scope isolate_scope(isolate); // 绑定 Isolate 到当前线程
    // 后续操作默认使用此 Isolate
  }
  ```

- **关键点**：必须先创建 `Isolate::Scope`，再使用其他作用域（如 `HandleScope`）。



### **2. `v8::HandleScope`**

- **作用**：管理 **本地句柄（Local Handles）** 的生命周期。

  - V8 使用句柄（`v8::Local<T>`）引用堆对象。
  - `HandleScope` 在栈上分配，析构时自动释放其作用域内创建的所有句柄。

- **生命周期**：对象存在期间创建的句柄会在其析构时被回收。

- **典型用法**：

  ```c
  v8::Isolate::Scope isolate_scope(isolate);
  {
    v8::HandleScope handle_scope(isolate); // 开始句柄作用域
    v8::Local<v8::String> str = v8::String::NewFromUtf8Literal(isolate, "Hello");
    // str 句柄在此作用域内有效
  } // 此处 handle_scope 析构，str 句柄被自动回收
  ```

- **关键点**：**每个函数入口点都需要一个 `HandleScope`**，避免句柄泄漏。



### **3. `v8::Context::Scope`**

- **作用**：设置当前执行的 **JavaScript 上下文（Context）**。

  - Context 是一个独立的全局环境（含全局对象、内置函数等）。
  - 用于隔离不同脚本的执行环境（如 iframe）。

- **生命周期**：对象存在期间，所有 JavaScript 代码默认在此 Context 中运行。

- **典型用法**：

  ```c
  v8::Local<v8::Context> context = v8::Context::New(isolate);
  {
    v8::Context::Scope context_scope(context); // 激活 Context
    // 此作用域内执行的脚本使用 context 的全局环境
    v8::Local<v8::Script> script = v8::Script::Compile(context, ...);
    script->Run(context); // 在 context 中运行
  } // 取消激活 Context
  ```

- **关键点**：用于切换 JavaScript 的全局执行环境。

### **三者的协作关系**

在典型 V8 初始化流程中，三者按以下顺序嵌套使用

```
// 1. 创建 Isolate
v8::Isolate* isolate = v8::Isolate::New(/* 参数 */);

{
  // 2. 绑定 Isolate 到当前线程
  v8::Isolate::Scope isolate_scope(isolate);
  
  // 3. 创建句柄作用域
  v8::HandleScope handle_scope(isolate);
  
  // 4. 创建 Context
  v8::Local<v8::Context> context = v8::Context::New(isolate);
  
  {
    // 5. 激活 Context
    v8::Context::Scope context_scope(context);
    
    // 6. 执行 JavaScript 代码	
    v8::Local<v8::String> source = v8::String::NewFromUtf8Literal(isolate, "1+2");
    v8::Local<v8::Script> script = v8::Script::Compile(context, source).ToLocalChecked();
    v8::Local<v8::Value> result = script->Run(context).ToLocalChecked();
  }
}
```

### 4.`v8::Locker`

`v8::Locker` 是 V8 中用于**多线程同步**的核心类，它确保对 Isolate 的线程安全访问：

### 关键特性

- **线程锁**：保证同一时间只有一个线程能访问特定 Isolate
- **互斥控制**：防止多个线程同时执行 JavaScript 或操作 V8 堆
- **GC 协调**：确保垃圾回收期间没有线程访问堆内存
- **作用域锁**：锁的生命周期由其作用域控制（RAII 模式）

### 基本用法

```c
v8::Isolate* isolate = v8::Isolate::New(/* 参数 */);

// 在需要访问 Isolate 的线程中
{
    v8::Locker locker(isolate);  // 锁定 Isolate
    v8::Isolate::Scope isolate_scope(isolate);
    // ... 执行 V8 操作 ...
} // locker 析构时自动解锁
```

```c
[线程入口]
   │
   ├── v8::Locker (多线程必备)
   │
   ├── v8::Isolate::Scope (绑定 Isolate)
   │
   ├── v8::HandleScope (管理句柄)
   │
   ├── v8::Context::New (创建上下文)
   │
   └── v8::Context::Scope (执行 JS)
        │
        └── JavaScript 操作
```
