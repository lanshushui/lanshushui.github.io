## 创建一个DLL(SO)文件

1.利用clion创建一个library工程，cmke文件如下

```cmake
cmake_minimum_required(VERSION 3.28)
project(librarydemo)

set(CMAKE_CXX_STANDARD 17)

add_library(librarydemo SHARED library.cpp)
```

2.创建build文件夹，并进入

2.执行命令  `cmake ../ -G "ninja"`  生成build.ninja相关文件。

> window下默认生成器是NMake Makefiles ，需要额外适配，而ninja工具在clion文件夹下有，所以用这个更方便
>
>  目录为：D:\CLion\bin\ninja\win\x64，配置在系统环境下

3.执行 ninja命令，生成dll文件，执行nm命令，查看符号

## Link一个DLL(SO)文件

1.利用clion创建一个aplication工程，cmke文件如下

[CMake中的link_directories与target_link_directories：用途与区别](https://cloud.baidu.com/article/3282135)

```2.cmake
cmake_minimum_required(VERSION 3.28)
project(executabledemo)

set(CMAKE_CXX_STANDARD 17)
add_executable(executabledemo main.cpp )
#给executabledemo文件 添加link的目录
target_link_directories(executabledemo PRIVATE ${CMAKE_SOURCE_DIR})
#实际link librarydemo
target_link_libraries(executabledemo  librarydemo)

```

2.将library.h，liblibrarydemo.dll文件复制到源目录下，修改main.cpp内容

```c++
#include "./library.h"
int main() {
    hello();
    return 0;
}
```

3.执行右上角运行，第一次会运行失败 **Error 0xc0000135**，因为执行link成功，但运行时还是找不到动态库。所以我们要把liblibrarydemo.dll文件再次复制到build目录下，即executabledemo.exe同级目录，再次运行即可正常运行
