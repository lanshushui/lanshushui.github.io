# hdc 命令

使用 hdc kill -r 命令可以杀掉异常进程并重启 hdc 服务。

如果 hdc list targets 获取不到设备信息，检查是否有 hdc 进程存在，并尝试重启 hdc 服务

查看内存分布 hdc shell hidumper --mem-smaps $pid -v

# hvigorw 命令

命令格式 hvigor [taskNames...] <options...> 官方文档

# 查看当前工程可用的 tasks

hvigorw tasks

# 打包 Hap

hvigorw assembleApp --mode project -p product=default -p buildMode=debug --no-daemon

# 打包 har

hvigorw assembleHsp --mode module -p product=default -p module=library@default --no-daemon
