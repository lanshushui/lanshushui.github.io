# 类解析

# 1. v8::Isolate::Scope

  • 作用：设置当前线程使用的 Isolate（隔离实例）。

    • Isolate 是 V8 的独立实例，拥有自己的堆内存、GC 等资源。
    • 多线程环境下，每个线程需绑定一个 Isolate。

  • 生命周期：对象存在期间，所有 V8 API 调用默认使用该 Isolate。

  • 典型用法：

  • 关键点：必须先创建 Isolate::Scope ，再使用其他作用域（如 HandleScope ）。

# 2. v8::HandleScope

  • 作用：管理 本地句柄（Local Handles） 的生命周期。

    • V8 使用句柄（ v8::Local<T> ）引用堆对象。
    • HandleScope 在栈上分配，析构时自动释放其作用域内创建的所有句柄。

  • 生命周期：对象存在期间创建的句柄会在其析构时被回收。

  • 典型用法：

  • 关键点：每个函数入口点都需要一个 HandleScope ，避免句柄泄漏。

# 3. v8::Context::Scope

  • 作用：设置当前执行的 JavaScript 上下文（Context）。

    • Context 是一个独立的全局环境（含全局对象、内置函数等）。
    • 用于隔离不同脚本的执行环境（如 iframe）。

  • 生命周期：对象存在期间，所有 JavaScript 代码默认在此 Context 中运行。

  • 典型用法：

  • 关键点：用于切换 JavaScript 的全局执行环境。

# 三者的协作关系

在典型 V8 初始化流程中，三者按以下顺序嵌套使用

// 1. 创建 Isolate
v8::Isolate* isolate = v8::Isolate::New(/* 参数 */);

{
  // 2. 绑定 Isolate 到当前线程
  v8::Isolate::Scope isolate_scope(isolate);
  
  // 3. 创建句柄作用域
  v8::HandleScope handle_scope(isolate);
  
  // 4. 创建 Context
  v8::Local<v8::Context> context = v8::Context::New(isolate);
  
  {
    // 5. 激活 Context
    v8::Context::Scope context_scope(context);
    
    // 6. 执行 JavaScript 代码	
    v8::Local<v8::String> source = v8::String::NewFromUtf8Literal(isolate, "1+2");
    v8::Local<v8::Script> script = v8::Script::Compile(context, source).ToLocalChecked();
    v8::Local<v8::Value> result = script->Run(context).ToLocalChecked();
  }
}

# 关键特性

  • 线程锁：保证同一时间只有一个线程能访问特定 Isolate
  • 互斥控制：防止多个线程同时执行 JavaScript 或操作 V8 堆
  • GC 协调：确保垃圾回收期间没有线程访问堆内存
  • 作用域锁：锁的生命周期由其作用域控制（RAII 模式）
